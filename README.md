# RUET Interactive Academic Calendar 2026

A fully responsive web-based application that digitizes the printed annual academic calendar of Rajshahi University of Engineering & Technology (RUET).

**Live Demo:** https://nahidreza45.github.io/ruet-calendar/

## Features

- **Interactive 2026 Calendar:** Saturday-start weekly grid highlighting RUET official holidays, Thursday–Friday weekly off days, past holiday fading, and interactive tooltips.
- **Live Today Bar:** Displays today's Gregorian, official Bangladesh Revised Bengali (Bangla Academy), and Hijri dates with automatic local fallback.
- **Bilingual Support (EN / বাংলা):** Switch smoothly between English and Bengali holiday listings with persisted preference.
- **Light & Dark Mode:** Opens in light mode by default, with a manual dark mode toggle that remembers your preference.
- **PNG Export & Print Ready:** Export any month's calendar as a high-resolution PNG or print cleanly directly from the browser.
- **University Directory:** Quick access to the Syndicate members and essential administration contacts (Registrar, Public Relations, DSW, Medical Center, Security) with click-to-call mobile links.
- **100% Responsive & Accessible:** Keyboard arrow navigation, mobile swipe support, screen-reader friendly ARIA roles, and seamless layouts across phones, tablets, and desktops.

## Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (single-file, zero-build)
- **Utilities:** Lazy-loaded `html2canvas` (with SRI) for PNG export, AlAdhan API with offline fallback for Hijri dates
- **Version Control & Hosting:** Git & GitHub Pages
