# RUET Interactive Academic Calendar

A fully responsive web-based application that digitizes the printed annual academic calendar of Rajshahi University of Engineering and Technology (RUET).

## Features

- **Interactive Calendar:** View official holidays and academic dates clearly highlighted.
- **University Directory:** Quick access to the Syndicate members and essential administration contact details (Registrar, DSW).
- **Click-to-Call Functionality:** Integrated mobile-optimized links that directly trigger the device dial pad for all listed office contacts.
- **100% Responsive Design:** Built to ensure seamless navigation across mobile devices, tablets, and desktops.

## Tech Stack & Workflow

- **Frontend:** HTML5, CSS3, JavaScript
- **Development Platform:** Google Antigravity (Agentic AI-assisted workflow for rapid prototyping and responsive layouts)
- **Version Control:** Git & GitHub
